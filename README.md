# Gerador de Box Shadow

Ferramenta web para criar sombras CSS visualmente. Você ajusta os controles e copia a regra pronta para o seu CSS.

**🔗 Demo:** https://box-shadow.vercel.app

## Funcionalidades

- Controles deslizantes para deslocamento horizontal e vertical, desfoque e espalhamento
- Seletor de cor e opacidade da sombra
- Pré-visualização em tempo real
- Geração da regra `box-shadow` (com prefixos `-webkit-` e `-moz-`) pronta para copiar
- Páginas de política de privacidade, termos e contato (site publicado)

## Tecnologias

HTML5 · CSS3 · JavaScript (manipulação de DOM, sem bibliotecas)

## Rodando localmente

```bash
git clone https://github.com/wagnerglongo/Box-shadow.git
cd Box-shadow
npx serve .
```
